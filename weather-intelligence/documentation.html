ML‑Weather – Full‑Stack Technical Overview

Versi: v0.1.0‑untrained • Last update: 2026‑10‑18

🚀 Core Architecture

Rust monorepo weather‑intelligence with 8 crates (wi‑core, wi‑model, wi‑storage, wi‑ingest, …). Uses Burn 0.22 for tensor ops and GNN inference.

  • 🧩 wi‑model – GraphCast GNN (12 layers, temporal attention).
  • ⚡ wi‑storage – Parquet + Redis cache (high‑performance I/O).
  • 📥 wi‑ingest – GRIB2 & NetCDF parsers (pure‑Rust).
  • 🔗 wi‑core – Shared types, error handling, utilities.

🛠️ Build & Feature Flags

GPU back‑ends are optional via Cargo feature flags (default cpu).

cargo build               # CPU (default)
cargo build --features wgpu   # GPU cross‑platform (Vulkan/Metal/DX12)
cargo build --features cuda   # NVIDIA CUDA

All GPU code is behind #cfg gates; binary size stays minimal for CPU‑only deployments.

🔁 Runtime Device Selection

Use GraphCastForecaster::with_best_device(config)?. Prioritas:

  1. CUDA (if available & feature enabled)
  2. WGPU
  3. CPU (fallback)

Auto‑selection removes manual device configuration and guarantees graceful degradation.

⚙️ Inference Pipeline

  • Tile‑based inference – region split into tiles, each processed independently.
  • Rayon parallelism for CPU tiles inside tokio::task::spawn_blocking. Each thread owns a local GraphCastModel (NdArray safe).
  • Synchronous path – predict_cells_sync() used by Rayon (no async/await inside parallel iter).
  • Edge cache – RwLock stores mesh edges per tile size. Reduces ~15 ms per tile rebuild.
  • Device accessor – forecaster.device() for benchmarks and external tools.

📊 Benchmarks (Criterion)

Run with cargo bench -p wi-model --bench inference_bench.

  • Single‑tile throughput (100 → 10 k cells) – measures pure forward pass.
  • Mesh‑edge build cost – 1 k → 50 k cells, cache bypass.
  • Edge‑cache warm vs cold – demonstrates > 10× speedup after first call.
