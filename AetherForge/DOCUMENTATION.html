Re-arsitektur yang Diimplementasi

Batch Inference

create_batch_input() membangun tensor [N, features] untuk N cell sekaligus, satu forward() call untuk semua cell. Tidak lagi per-cell sequential.

Mesh Graph

build_mesh_edges() membangun edge_index [2, E] dengan 4-connectivity untuk GNN message passing.

Spatial Tiling

TilingManager::split_area_into_tiles() bagi area besar menjadi tile (default 2,5M cell/tile) dengan overlap untuk konsistensi GNN di batas tile.

Multi-Area Coordinator

TileCoordinator::infer_area_distributed() otomatis split ke tiles, process secara concurrent via futures::future::join_all.

Device Selection

DeviceType (CPU/CUDA/WGPU/Metal) via create_burn_device().

Lead Time Cap

MAX_LEAD_SECONDS = 168 * 3600 enforced di semua entry point.

No unwrap/panic/race

Semua operasi via Result, tidak ada unwrap()/expect()/panic! di non-test code.

Alur Penggabungan (5 Langkah)

  1. Ingest mentah dengan metadata: sumber, lisensi, waktu terbit, waktu berlaku.
  2. Selaraskan grid, satuan, zona waktu (UTC), nama variabel.
  3. Saring pengamatan (QC): rentang nilai, konsistensi antar stasiun, data ganda.
  4. Gabungkan: fisika (GFS/GEFS) sebagai dasar, AI (AIGFS/AIGEFS/BMKG_fc) sebagai anggota tambahan. Bobot dipelajari dari data historis.
  5. Verifikasi terhadap pengamatan, bukan ERA5.

Pola Pembobotan (Weighting Pattern)

A. Bias Correction (Additive)

x_koreksi = x_prakiraan - b
b_baru = (1 - α) * b_lama + α * (prakiraan - pengamatan)
  • α dan panjang jendela BELUM DIPUTUSKAN → WIError::BelumDiputuskan
  • Variabel aditif: suhu 2m, tekanan permukaan laut, angin (u,v), kelembapan (clamp 0-100%)
  • Hujan: BUKAN aditif — pakai rasio, clamp ≥ 0
  • Semua anggota ensemble pakai b yang sama
  • Acuan: obs.bmkg_stn, obs.isd (setelah QC), BUKAN ref.era5

B. Ensemble Probability

p = (1/M) * Σ(1[x_m > T])
  • Hazard function dijalankan pada SETIAP anggota ensemble, baru proporsi dihitung
  • M kecil → probabilitas kasar (0 atau 1)

C. Fusion Weight (constraint: Σw = 1, w ≥ 0)

Fusion = w_physics * Base(GFS, GEFS)
       + w_ai * Σ(w_member_i * Member_i)   [AIGFS, AIGEFS, BMKG_fc]
       + BiasCorrection(...)
       → Calibrated Probability via Ensemble CDF
  • Σ w = 1, w ≥ 0, divalidasi oleh FusionEngine::validate_weights()
  • Nilai konkret bobot belum ditetapkan — harus diturunkan dari verifikasi historis
  • Fisika (GFS, GEFS) = baseline weight tinggi
  • AI members (AIGFS, AIGEFS) = weight tambahan, bukan pengganti fisika

  • JWT RS256 Authentication - scope-based authorization
  • Rate Limiting - sliding window, Redis-backed
  • CORS - configurable origins
  • Request Validation - lat/lon bounds, lead time max (168h), variable names
  • Redis Cache - TTL (1hr point, 30min grid), pattern invalidation
  • Tracing - structured JSON with cell, model_run, latency

ML Pipeline — Dual Path

Path 1: Global Model (Burn GraphCast)

12 GNN layers, 8 heads, hidden_dim=256, ~40-60M params. SwiGLU MLP, O(N) Linear Attention (Performer). 17 output heads.

Path 2: Regional Downscaler (ONNX)

Input 14 features → Output 6 vars × 4 quantiles = 24 outputs. ort crate Level3, 4 intra-threads.

Training

Python melatih, Rust menyajikan. PyTorch/Lightning → ONNX/Burn → serve in Rust.

Compliance (Wajib)

  • UU 31/2009 Pasal 36 ayat 1 + PP 11/2016 Pasal 4: Info meteorologi hanya oleh BMKG, kecuali UU lain.
  • Istilah: "informasi risiko" atau "analisis pendukung", bukan "peringatan dini" sebelum izin BMKG.
  • Atribusi: BMKG wajib, FIRMS acknowledgment, Copernicus/Open-Meteo atribusi, NOAA tidak boleh disiratkan didukung NOAA.
  • Open-Meteo: gratis hanya non-komersial, <10.000 panggilan/hari.
  • BMKG: 60 req/min/IP, izin tertulis untuk komersial.
  • NOMADS: ~120 hit/min/user, pusatkan unduhan pada satu node dengan rate limiter.
  • GraphCast/GenCast bobot: CC BY-NC-SA 4.0 → dikecualikan untuk produk komersial.

Gerbang Sebelum Penyajian

  1. Istilah keluaran sesuai dan tidak menyebut "peringatan dini" tanpa izin.
  2. Atribusi lengkap: BMKG wajib, FIRMS acknowledgment, Copernicus/Open-Meteo atribusi.
  3. Tidak ada sumber berstatus belum dan tidak ada sumber tidak independen yang terhitung dua kali.
  4. Bahasa probabilitas dan tingkat risiko, tanpa klaim "memprediksi pasti".
  5. Skor verifikasi pilot sudah melewati ambang kelulusan.

Undecided (JANGAN diisi tebakan)

  • α dan panjang jendela koreksi bias → BelumDiputuskan error
  • Ambang tingkat siaga (longsor/banjir/asap)
  • Model sebaran asap
  • Indeks kekeringan
  • Sumber sungai, tanah, tutupan lahan, drainase, dll.
  • BMKG PNBP tariff, PVMBG download rights, GPM/GSMaP licenses
  • Commercial product decision

Arsitektur Deployment — Three VPS Topology

Engine didesain untuk berjalan dalam tiga VPS terpisah untuk memisahkan tanggung jawab ingestion, inference, dan API. Untuk development/prototype, semua dapat dijalankan dalam satu VPS.

VPS-1: Data Pipeline

Tugas: Ingest, validasi, penyimpanan, koreksi bias

  • wi-ingest (7 adapters)
  • wi-storage (Parquet, PostGIS, Redis)
  • BiasCorrectionEngine
  • Checkpoint sync (SHA256)

VPS-2: ML Engine (GPU)

Tugas: Inferensi GraphCast, tiling, distributed

  • wi-model (Burn, ONNX)
  • TilingManager + TileCoordinator
  • CUDA/WGPU device
  • 38.9M cell inference

VPS-3: API + Frontend

Tugas: API gateway, UI, CoalForge integration

  • wi-api (REST + gRPC)
  • JWT auth, rate limiting
  • Leptos + MapLibre UI
  • CoalForge decision endpoints

cargo run --bin wi -- sync --hours 24
cargo run --bin wi -- ingest

# VPS-2: ML Engine (dengan GPU support)
cargo run --bin wi-serve --features cuda -- --port 8081

# VPS-3: API + Frontend
